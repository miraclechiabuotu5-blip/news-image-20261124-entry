A deterministic Python program that draws one 1024x1024 image summing up 24 November 2026 world news: Riyadh hit, Ukraine sinking a Russian warship off Libya, Zaporizhzhia, Gaza, Russia warning Estonia, and Nvidia's CEO returning, with COP31, Senegal winning AFCON, and NATO space defence in the footer.

## Run it

```sh
python3 main.py
```

The program writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (or `/output/entry.png` when run by make.fun). It uses only the Python standard library, no network, no randomness, and no time, so two runs write exactly the same bytes.
